# Hospital Management System (HMS)

## Vision
A centralized digital platform to streamline hospital operations, including patient care, staff management, and financial tracking. The system aims to provide a "Modern Minimalist" experience that is efficient, accessible, and secure.

## Core Goals
- **Patient Empowerment:** Easy registration, appointment booking, and access to medical history.
- **Clinical Efficiency:** Streamlined OPD/IPD workflows, electronic prescriptions, and lab management.
- **Operational Excellence:** Effective staff and bed management, inventory tracking, and real-time dashboards.
- **Financial Integrity:** Automated billing, payment tracking, and financial reporting.

## Target Audience
- **Admins:** System configuration, staff management, and oversight.
- **Doctors/Nurses:** Clinical documentation, prescriptions, and patient care.
- **Receptionists:** Patient registration and appointment scheduling.
- **Patients:** Self-service portal for appointments and records.
- **Lab Technicians:** Managing test requests and results.
- **Pharmacists:** Inventory and medicine dispensing.

## Tech Stack
- **Frontend:** React / Next.js (TypeScript)
- **Backend:** Node.js (Express)
- **Database:** PostgreSQL
- **Auth:** Email/Password + Google OAuth
- **Styling:** Vanilla CSS (Modern Minimalist, Mobile-first)
- **Deployment:** Vercel/Netlify (Frontend), Render/Fly.io/Azure (Backend)

## Success Metrics
- Performance: < 200ms API response time for common queries.
- Security: Role-based access control (RBAC) enforced.
- UX: Intuitive navigation with < 3 clicks to reach any primary feature.
